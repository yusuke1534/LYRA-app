LYRA UI プレビューアプリ

【現時点の機能】
- スマホ専用ホーム画面／PCでのロゴや紹介パネル付きレイアウト
- ホーム、トーク、通話、AI、マイページの切替
- 友だち一覧、友だち追加（デモ）、グループ作成（デモ）
- メッセージ送信、絵文字、写真共有、検索、お気に入り
- プロフィール編集、端末内ローカル保存
- オフライン対応（HTTPS環境で初回アクセス後）

【まだ接続していない機能】
- 実在の別ユーザーとのメッセージ送受信
- 音声・ビデオ通話
- 生成AIによる回答（現在は定型デモ応答）
- ユーザー登録・ログイン・友だち招待QR

【公開手順】
1. ZIPを解凍します。
2. GitHub Pagesのレポジトリのルートに index.html, manifest.webmanifest,
   service-worker.js と assets フォルダをそのままアップロードします。
3. GitHub Pagesで公開するとスマートフォンからアクセスできます。
4. iPhone Safari の共有ボタン → ホーム画面に追加 でアプリアイコンが作れます。

※ 絵や人物写真はデザイン画像由来のサンプルです。
※ 実際の通信アプリとして運用するには、バックエンドとプライバシー・安全対策が必要です。
